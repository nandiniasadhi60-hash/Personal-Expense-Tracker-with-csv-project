
# Personal Expense Tracker with CSV

## Project Description
Personal Expense Tracker is a Python application used to record,
manage, and track daily expenses. It stores expense information
in a CSV file using Python CSV file handling.

## Features
- Add daily expenses
- View all expense records
- Calculate total expenses
- Search expenses by category
- Store records permanently in CSV format
- Validate user input

## Technologies Used
- Python
- CSV File Handling
- DateTime Module
- VS Code

## Project Structure
PersonalExpenseTracker/
- expense_tracker.py
- expenses.csv
- README.md

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python expense_tracker.py

5. Select an option from the menu.
6. Add and manage your expenses.

## Project Objective
To develop a simple expense management system
using Python and CSV file handling.
